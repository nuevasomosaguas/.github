# Nueva Somosaguas

Una facultad abierta de ciencias sociales analíticas y cuantitativas. Enseña a explicar cómo ocurre lo social: formular cada mecanismo con precisión, contrastarlo con datos y reconstruirlo con código. Todo es abierto, desde el currículo y la biblioteca hasta las guías, el código y los laboratorios, y no hay matrícula ni títulos.

**Web:** [nuevasomosaguas.github.io](https://nuevasomosaguas.github.io)

## Los repositorios

**La facultad**
- [nuevasomosaguas.github.io](https://github.com/nuevasomosaguas/nuevasomosaguas.github.io): la web, con el currículo, la biblioteca, sus rutas de lectura y la guía autodidacta.
- [bootcamp](https://github.com/nuevasomosaguas/bootcamp): guías, cuadernos y evaluación automática del bootcamp de nivelación.
- [laboratorios-y-simulaciones](https://github.com/nuevasomosaguas/laboratorios-y-simulaciones): problemas de ciencias sociales que se resuelven con R en el navegador.
- [entorno](https://github.com/nuevasomosaguas/entorno): el entorno de trabajo, con Julia, R, Python, SQL, Quarto y Typst, listo para Codespaces.

**Proyectos**
- [fdrmania](https://github.com/nuevasomosaguas/fdrmania): la tasa de falsos descubrimientos contra el *p-hacking*.
- [ns-for-ie](https://github.com/nuevasomosaguas/ns-for-ie): la prueba de acceso inversa.
- [corpus-rag-biblioteca](https://github.com/nuevasomosaguas/corpus-rag-biblioteca): la ingesta y estructuración de la biblioteca para un RAG local.

**Estilo**
- [somosaguas-quarto-theme](https://github.com/nuevasomosaguas/somosaguas-quarto-theme), [somosaguas-hugo-theme](https://github.com/nuevasomosaguas/somosaguas-hugo-theme), [somosaguas-typst-template](https://github.com/nuevasomosaguas/somosaguas-typst-template), [somosaguas-ggplot2](https://github.com/nuevasomosaguas/somosaguas-ggplot2), [somosaguas-makie](https://github.com/nuevasomosaguas/somosaguas-makie) y [somosaguas-vscode](https://github.com/nuevasomosaguas/somosaguas-vscode): la maquetación y el estándar gráfico de la casa para Quarto, Hugo, Typst, R, Julia y VS Code.
